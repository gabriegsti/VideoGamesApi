This is a Video game Api where we can store information about video games played and owned. 

It is being developed using net 10 and vertical slice architecture. 

First step to run the project is to install dotnet 10 SDK from the official Microsoft website.

Also you will need a visual studio code 2026 or later version to run the project.

The project is already using a webapi client called Scalar. 

Scalar will help you to make requests to the api and get responses in a simple way.
